# Horizon Warehouse Olympics Team Wayfinder

Interactive team schedule prototype for the Horizon 2026 Warehouse Olympics.

Attendees can select their wave, color team, squad, and packing relay to view their Picking, Packing, and Conveyor assignments.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

This is a static site and does not require a build step. GitHub Pages can publish it directly from the root of the `main` branch.

## Privacy

The prototype contains team assignments and event timing only. It does not contain attendee names or personal information.
